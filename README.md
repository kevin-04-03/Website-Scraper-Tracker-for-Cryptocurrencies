## Name
Website Scraper Tracker for Cryptocurrencies

## Description
This project is an automated data management pipeline designed to scrape, track, store, and visualize the real-time prices of major cryptocurrencies (Bitcoin, Ethereum, and Solana). 

The system utilizes Python scripts to scrape pricing data from the web, Bash scripts to handle data exportation, SQL for database structuring, and Gnuplot to automatically generate price trend visualizations. It is designed to be run as an automated task (via Crontab) to continuously monitor the cryptocurrency market over time.


## Visuals
The project automatically generates trend graphs for the tracked cryptocurrencies. Below are examples of the visual outputs generated by Gnuplot:

## Installation & Requirements
To run this project on your local machine, you will need to have the following installed:
* **Python 3.x** (Along with any scraping libraries used, e.g., `pip install requests beautifulsoup4 pandas`)
* **Gnuplot** (For generating the graphs)
* **Bash/Linux Environment** (For executing `.sh` scripts)
* **Cron** (For scheduling automated tracking)
* **SQL Database system** (e.g., MySQL, SQLite, or PostgreSQL)

bash

cd data_management_cw2_ethan_kevin

## Usage
1. Manual Data Collection:
You can manually trigger data collection for specific coins using the Python scripts:

Bash
python3 bitcoin_data_collection.py
python3 ethereum_data_collection.py
python3 solana_data_collection.py

2. Exporting Data:
To export the current datasets, use the provided Bash scripts:

Bash
./export_all_data.sh

3. Generating Visualizations:
Run the Gnuplot scripts to update the PNG graphs based on the latest CSV data:

Bash
gnuplot plot_all_data.gnu

## Program usage precaution
Important Configuration Note: This project relies on absolute/relative directories to read and write files (CSVs, PNGs, and Logs). Before running the automated pipeline, you must change the directory paths inside the code to match your personal machine's environment setup.

The files affected by directory paths include:

Python files (*_data_collection.py)

Bash Script files (export_*.sh)

Gnuplot files (plot_*.gnu)

Crontab (Local automation setup)
